# AMR Task Allocation System

A warehouse simulation platform for intelligent task
allocation across heterogeneous autonomous mobile robots.

## Objectives

- Implement nearest-available robot allocation.
- Develop a workload-aware allocation policy.
- Compare makespan and robot utilisation fairness.
- Measure tasks completed per hour.
- Visualise robot movement and allocation timelines.

## Tech Stack

- React
- Tailwind CSS
- Python
- FastAPI
